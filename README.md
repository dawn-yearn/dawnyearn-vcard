# Danyang Zhang · Personal Page

A personal vCard-style website adapted from **codewithsadee/vcard-personal-portfolio**.

## Sections

- About
- Resume
- The Self
- Dating
- Contact

## Run locally

This is a static site. You can open `index.html` directly, or run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

The site can be deployed directly to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static host.
